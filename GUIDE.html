User Guide · v1.0

open-scraper

Two read-only scrapers that work on any public website

page_scraper.py grabs pages right now and saves them as clean Markdown. daemon.py keeps watching a list of pages and saves a copy every time something actually changes.

No accounts. No API keys. No passwords. The tools only ever send plain GET requests — they cannot log in anywhere, by design.

1 Install

One time only. Takes about two minutes.

You need Python 3.10 or newer. Check yours:

Terminal 
$ python3 --version
$ Python 3.14.7

Copy and paste these four commands

Terminal 
$ git clone https://github.com/arushvantore/open-scraper.git
$ cd open-scraper
$ python3 -m venv .venv
$ .venv/bin/pip install -r requirements.txt
$ .venv/bin/playwright install chromium
What these do git clone copies the repo  ·  venv makes a private Python sandbox for this project  ·  pip install pulls in Playwright  ·  playwright install chromium downloads the browser it drives.
Windows Use .venv\Scripts\python everywhere this guide writes .venv/bin/python. The rest is identical.

Check it worked

Terminal 
$ .venv/bin/python page_scraper.py https://example.com
You should see 
open-scraper :: 1 page(s) -> output/
  GET   https://example.com
  SAVE  output/example-com.md  (133 words, hash a4ccdd75cf70ea93)

Done. 1 ok, 0 skipped/failed.

If you see SAVE output/example-com.md, installation is finished. If you see an error, jump to Troubleshooting on the last page.

From here on, every command starts with cd open-scraper (or cd ~/open-scraper if you cloned it into your home folder).

2 Scrape a single page

The most common thing you will do. One command, one file.

Terminal 
$ cd open-scraper
$ .venv/bin/python page_scraper.py https://example.com
Output 
open-scraper :: 1 page(s) -> output/
  GET   https://example.com
  SAVE  output/example-com.md  (133 words, hash a4ccdd75cf70ea93)

Done. 1 ok, 0 skipped/failed.

Open output/example-com.md. It looks like this:

output/example-com.md 
---
url: https://example.com/
title: Example Domain
fetched: 2026-10-27T19:51:56Z
selector: (whole page)
word_count: 133
content_hash: a4ccdd75cf70ea93
---

# Example Domain

This domain is for use in documentation examples without needing
permission. This is not a service; avoid relying on it for testing
and monitoring purposes.
What survived the conversion Headings, links, lists, quotes, code blocks and images all become clean Markdown. Scripts, styles and navigation menus are thrown away — so what you get is the actual content of the page.

Scrape several pages at once

Just list them, separated by spaces:

Terminal 
$ .venv/bin/python page_scraper.py https://a.com https://b.com https://c.com

It fetches them one at a time, with a 2-second pause between each, so you are never hammering a server.

3 Grab only part of a page

Use --selector when you want the article, not the whole site chrome.

Without a selector you get everything. With one, you get just that element:

Terminal 
$ .venv/bin/python page_scraper.py https://www.python.org/downloads/ --selector "#content" --links
Output 
open-scraper :: 1 page(s) -> output/
  GET   https://www.python.org/downloads/
  SAVE  output/www-python-org-downloads.md  (2379 words, hash 2b14189d3b4d6968)

Done. 1 ok, 0 skipped/failed.

The file now starts with selector: #content in its header, and ends with a Links section listing every URL found inside it (because we passed --links).

How to find a selector — 4 steps

  1. Open the page in Chrome, Firefox or Edge.
  2. Right-click the piece of text you want → Inspect.
  3. In the panel that opens, right-click the highlighted line of HTML → Copy → Copy selector.
  4. Paste it after --selector, wrapped in quotes.
Example 
$ .venv/bin/python page_scraper.py https://blog.example.com/post \
     --selector "article.post-body"
Selector matched nothing? The tool stops and says so, rather than saving an empty file. Re-copy the selector, or drop --selector entirely to take the whole page.

Three more flags you will use

FlagWhat it adds
--screenshot A full-page .png saved next to the Markdown file.
--wait 5000 Waits 5 seconds for JavaScript to finish. Use on pages that render late.
--json summary.json A machine-readable summary of everything you just scraped.

4 Scrape a list of pages from a file

For anything longer than a handful of URLs.

Edit the file called targets.txt that sits in the repo root. Paste one URL per line. Lines starting with # are ignored.

targets.txt 
# One URL per line. Lines starting with # are ignored.
# Only public pages here - this tool cannot log in anywhere.

https://example.com
https://www.python.org
https://news.ycombinator.com
Three rules Every URL must start with https:// · one URL per line · no quotes or commas needed. Anything else and the tool stops with a clear message telling you which line is wrong.

Then run it:

Terminal 
$ .venv/bin/python page_scraper.py --targets targets.txt
Real output 
open-scraper :: 3 page(s) -> output/
  GET   https://example.com
  SAVE  output/example-com.md  (133 words, hash a4ccdd75cf70ea93)
  GET   https://www.python.org
  SAVE  output/www-python-org.md  (1409 words, hash c4779ed592c5605c)
  GET   https://news.ycombinator.com
  SAVE  output/news-ycombinator-com.md  (598 words, hash 1bf66fb2282146f5)

Done. 3 ok, 0 skipped/failed.

Three files are now in output/. Use --out mydir to send them somewhere else, and --pause 5 to slow down between pages.

Same file works for both tools targets.txt is read by page_scraper.py and by daemon.py. Maintain one list, drive both tools from it.

5 Watch pages for changes (the daemon)

Re-checks your list on a timer and archives only what actually changed.

Terminal — run forever, checking every 5 minutes 
$ .venv/bin/python daemon.py --targets targets.txt --interval 300
Terminal — run a single check and exit (good for schedulers) 
$ .venv/bin/python daemon.py --targets targets.txt --once

Press Ctrl-C to stop. It finishes the page it is on, saves its state, prints daemon stopped, and exits cleanly.

First run — everything is new

Unchanged pages are not re-archived, so your folder never fills up with identical copies.

Daemon flags worth knowing

FlagDoes
--interval NSeconds between checks. Default 300 (5 min).
--onceOne check, then exit.
--diff-onlyLog changes but write no archive files.
--selector "css"Watch one element instead of the whole page.
--log FILEWhere the timeline goes. Default daemon.log.

6 Where your files go

Everything lands in the output/ folder — on your machine only.

output/ ├── live/ current state of each watched page (daemon) ├── archive/ one file per real change, stamped (daemon) │ e.g. 20261027_204620_example-com.md ├── *.md one-shot scrapes (page_scraper) ├── *.png screenshots, if you used --screenshot └── .state.json hashes the daemon uses to spot change
Important — this folder is gitignored output/ is listed in .gitignore, so scraped content can never be pushed to GitHub by accident. Your captures stay on your computer. The same is true of daemon.log and the .venv/ folder.

7 Keep the daemon running after you close the terminal

Optional. Only needed if you want it running unattended.

By default the daemon lives only while its terminal window is open. To make it start on login and survive reboots, hand it to your operating system.

macOS — launchd

Terminal 
$ mkdir -p ~/Library/LaunchAgents
$ cat > ~/Library/LaunchAgents/com.example.scraper.plist <<'XML'
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN"
  "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0"><dict>
  <key>Label</key><string>com.example.scraper</string>
  <key>ProgramArguments</key><array>
    <string>/ABSOLUTE/PATH/open-scraper/.venv/bin/python</string>
    <string>/ABSOLUTE/PATH/open-scraper/daemon.py</string>
    <string>--targets</string>
    <string>/ABSOLUTE/PATH/open-scraper/targets.txt</string>
    <string>--interval</string><string>300</string>
  </array>
  <key>WorkingDirectory</key>
  <string>/ABSOLUTE/PATH/open-scraper</string>
  <key>RunAtLoad</key><true/>
  <key>KeepAlive</key><true/>
</dict></plist>
XML
$ launchctl load ~/Library/LaunchAgents/com.example.scraper.plist
Replace every /ABSOLUTE/PATH with the real location, e.g. /Users/you/open-scraper. Then stop it with launchctl unload ~/Library/LaunchAgents/com.example.scraper.plist.

Linux — cron, every 10 minutes

Run crontab -e and add this line 
*/10 * * * * cd /path/open-scraper && .venv/bin/python daemon.py --targets targets.txt --once >> daemon.log 2>&1

Windows — Task Scheduler

Create a task that runs C:\path\open-scraper\.venv\Scripts\python.exe daemon.py --targets targets.txt --once, starting in C:\path\open-scraper, and tick "Run whether user is logged on or not".

A ready-to-edit copy of the launchd file and cron line also lives in README.md in the repository.

8 Troubleshooting & the rules

What goes wrong, what it means, and how to fix it.

Message you seeWhat it means / fix
Playwright is not installed Run .venv/bin/pip install -r requirements.txt.
Browser / executable errors Run .venv/bin/playwright install chromium.
Skip … (robots.txt disallows) Expected — that site asked not to be scraped. Add --no-robots only if you own it.
Timeout 30000ms exceeded Slow site. Raise it: --timeout 60.
Output is empty The page renders with JavaScript. Try --wait 5000, or add --selector.
Selector … matched nothing Re-copy the CSS selector from your browser's DevTools.
Targets file not found Wrong path, or you are not in the repo folder. Run cd open-scraper first, or pass URLs directly instead.
these are not http(s) URLs A line in targets.txt is missing https://.
Daemon stops when I close the terminal Normal — see section 7 to have the OS start it for you.

The rules these tools follow

Read-only, always They send GET requests and nothing else. They never submit a form, never post, never like, follow or upload. There is no password, cookie or session handling anywhere in the code — if a page is behind a login, these tools cannot open it.
robots.txt is respected by default If a site's robots file says "do not fetch this", the tool skips it and prints SKIP. You have to ask for --no-robots explicitly.
Your responsibility Only scrape pages you are allowed to scrape, and follow each site's Terms of Service. Politeness defaults (one page at a time, 2-second pauses) are there for a reason — use --pause to slow down further on small sites.
Nothing personal is in this repository No credentials, no browser profiles, no scraped data. Everything you capture goes into output/, which is gitignored.
